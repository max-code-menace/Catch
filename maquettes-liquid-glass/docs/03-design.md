# Catch — Design

15 novembre 2026.

## La direction : liquid glass gris

Une seule matière de verre translucide, qui prend la couleur de la carte derrière elle. Gris clair pour les panneaux, gris foncé pour le menu. Une seule couleur vive, pour l'action principale.

Elle mélange ce qui a été retenu dans la galerie des 10 directions (`inspiration/galerie-partant-10-directions.html`) : la H (verre, carte toujours visible), la A (orange vif), la B (compte à rebours), la D (sobriété des fiches), la F (places libres en ronds vides, réponses rapides), et le menu en verre de `inspiration/menu-verre-reference.jpg`.

| Élément | Valeur |
| --- | --- |
| Police | Inter (400, 500, 600, 700), chiffres alignés |
| Texte | `#1C1C1E` ; secondaire `#4A4A50` |
| Verre clair | `rgba(242,242,247,0.62–0.80)`, flou 24–30 px, saturation 180 %, liseré blanc |
| Verre foncé (menu) | `rgba(44,44,48,0.66)`, flou 24 px, saturation 180 % |
| Couleur d'action | Orange `#FF5A36` par défaut (texte foncé dessus) ; à décider |
| Carte | sol `#DDE3E6`, parcs `#B9D3A8`, eau `#9CC6E0`, rues blanches |
| Rayons | pilules 20–28 px, panneaux 26–34 px |
| Cibles | 40 px minimum |

## Les 8 règles (inspirées de Raven)

1. Un seul aplat de couleur par écran : le geste attendu (Je suis partant, Catch, Publier).
2. Le reste est en gris, noir ou blanc. Ce qui est sélectionné passe en noir, jamais en couleur.
3. Une couleur n'est jamais seule : toujours doublée d'un mot (« il manque 2 »).
4. Un seul titre par écran. Le secondaire en gris.
5. Les chiffres alignés (heures, places, scores).
6. Capitales seulement pour les petits intitulés espacés.
7. Seul ce qui flotte sur la carte a une ombre ; ailleurs, tout est à plat.
8. Un bouton dit ce qui se passe. Pas d'emoji. Rien de cliquable sous 40 px.
