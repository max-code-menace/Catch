# UX writing

Audit complet : [Catch — audit UX writing](https://claude.ai/artifact/PZ9qBxvU5qQ3sL4izGLaT4) (47 corrections, toutes appliquées au design v1).

## Ton

Tutoiement partout, phrases courtes, aucun jargon. Pas de promesse qu'on ne peut pas tenir (« en 5 secondes », « on te garde ta place »). Boutons avec un verbe. Messages système en français neutre.

## Le mot « catch »

- **Bouton** : « Catch » seul.
- **Verbe** : « catcher », conjugué et accordé : « Tu l'as catchée ! », « Connecte-toi pour la catcher ».
- **Pour quelqu'un qui ne connaît pas l'app** (page web d'invitation) et dans les messages système : « Rejoindre », « Tu as rejoint la session ».

## Glossaire

| Terme retenu | Sens | À éviter |
| --- | --- | --- |
| Session | Un créneau de sport à un lieu et une heure | match, partie, événement |
| Créer une session | Organiser une session | lancer, ajouter |
| Annuler ma participation | Quitter une session catchée | relâcher, se désinscrire |
| En direct | Session commencée, encore joignable | live, maintenant (en badge) |
| Il manque X joueur(s) | Session qui a besoin de monde | cherche un joueur |
| Places libres | Ce qui reste à prendre | places (seul) |
| Inscrits | Total de personnes déjà dans la session | joueurs (pour un total) |
| Jouent | Uniquement pour une session en direct | inscrits (en direct) |
| Joueurs | Nombre maximum choisi à la création | places (dans Créer) |
| Débutants bienvenus | Toujours cette formule | tous niveaux |
| Organisée par | Créateur de la session | par, hôte |
| Inviter | Partager le lien d'une session | partager, envoyer |
| Messages | L'onglet et les conversations | messagerie, chat |

Formats : « Jeu. 19h » en liste, « Jeudi 20 novembre · 19h » en détail, « Ce soir 19h » pour aujourd'hui, heures « 19h02 », distances « à 600 m ».

## Textes encore à dessiner

Ces textes sont rédigés mais n'ont pas encore d'écran :

- **Permissions** : localisation (« Voir les sessions près de toi », avec « Choisir ma commune » si refus) et notifications (demandées juste après le premier Catch).
- **Erreurs** : plus de réseau, session devenue complète pendant le Catch, échec serveur.
- **Annulation** : toast « Tu as quitté la session » avec « Annuler » pendant 5 s ; dialogue si moins de 3h avant.
- **Suppression de compte** : dialogue « Supprimer ton compte ? … C'est définitif. »
- **Notifications** : rappel 3h avant avec « Je viens » / « Je ne peux plus », nouveau message, joueur manquant, nouvelle session de ton sport (1 par jour maximum).
- **États vides** : Messages, Profil sans session à venir.
- **Première utilisation** : une bulle sur la carte, une sur Créer.

Le détail de chaque texte est dans l'audit.
